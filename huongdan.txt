Tôi sẽ viết lại website “Những ngày đáng nhớ” thành một phiên bản hoàn chỉnh, có cấu trúc rõ ràng để bạn sử dụng với GitHub Pages. Mục tiêu là bạn chỉ cần chỉnh sửa một khu vực trong source code mỗi khi muốn thêm album hoặc thay ảnh, thay vì phải tìm và sửa nhiều đoạn code khác nhau.

Phiên bản này có các chức năng:

* Hiển thị nhiều album trên trang chủ.

* Bấm vào từng album để mở những ảnh kỷ niệm bên trong.

* Bấm vào ảnh để xem ảnh lớn, ngày tháng và lời chú thích.

* Tìm kiếm ảnh theo nội dung chú thích.

* Hiển thị phù hợp trên máy tính và điện thoại.

* Quản lý ảnh trực tiếp trong source code, không phụ thuộc vào chức năng tải ảnh lên từ giao diện website.

## 1. Tải source code hoàn chỉnh

Source code HTML hoàn chỉnh

Đã chia thành các phần, xuống dòng và thêm chú thích.

Tải file HTML

Bộ website dành cho GitHub Pages

Gồm file `index.html`, các thư mục ảnh mẫu và hướng dẫn.

Tải bộ website dạng ZIP

Tôi khuyên bạn tải bộ ZIP, giải nén ra máy tính rồi làm theo hướng dẫn bên dưới. Lưu ý: các đường dẫn ảnh trong code là tên file mẫu; bạn cần thêm ảnh thật vào thư mục tương ứng để hiển thị ảnh của hai bạn.

## 2. Bước 1 — Chuẩn bị thư mục website

Sau khi giải nén, bạn sẽ có cấu trúc như sau:

website-ky-niem/

`index.html`

Mã nguồn website

`images/`

`ngay-dau-tien/`

`hen-ho/`

`chuyen-di/`

`ngay-binh-thuong/`

Bạn có thể thêm ảnh của mình vào từng thư mục. Ví dụ, thư mục `ngay-dau-tien` có các file:

* `anh-bia.jpg` — ảnh bìa album.

* `anh-01.jpg` — ảnh kỷ niệm thứ nhất.

* `anh-02.jpg` — ảnh kỷ niệm thứ hai.

Bạn nên đặt tên file không dấu, viết thường và không có khoảng trắng để dễ quản lý.

## 3. Bước 2 — Thêm ảnh vào source code

Mở file `index.html` bằng Visual Studio Code. Nhấn `Ctrl + F`, tìm cụm:

`10. DỮ LIỆU ALBUM VÀ ẢNH`

Đây là phần duy nhất bạn thường xuyên cần sửa khi thêm album hoặc ảnh.

Ví dụ một album được khai báo như sau:

JavaScript

```
{
    // Mã định danh riêng của album
    id: "ngay-dau-tien",

    // Tên hiển thị trên website
    title: "Những ngày đầu tiên",

    // Lời giới thiệu
    description: "Những kỷ niệm đầu tiên của chúng mình.",

    // Ảnh bìa album
    cover: "images/ngay-dau-tien/anh-bia.jpg",

    // Danh sách ảnh bên trong album
    photos: [
        {
            src: "images/ngay-dau-tien/anh-01.jpg",
            caption: "Ngày đầu tiên chúng mình gặp nhau",
            date: "2026-05-18",
            description: "Hôm ấy là một ngày thật đặc biệt."
        },
        {
            src: "images/ngay-dau-tien/anh-02.jpg",
            caption: "Buổi hẹn đầu tiên",
            date: "2026-05-24",
            description: "Một kỷ niệm mà mình luôn muốn giữ lại."
        }
    ]
}
```

Ý nghĩa từng trường:

| Trường                  | Công dụng                                                  |
| ----------------------- | ---------------------------------------------------------- |
| `id`                    | Mã riêng để website nhận diện album. Không nên trùng nhau. |
| `title`                 | Tên album hoặc tên kỷ niệm.                                |
| `description`           | Lời giới thiệu hoặc câu chuyện về kỷ niệm.                 |
| `cover`                 | Đường dẫn ảnh bìa album.                                   |
| `photos`                | Danh sách ảnh xuất hiện bên trong album.                   |
| `src`                   | Đường dẫn đến file ảnh trên GitHub.                        |
| `caption`               | Chú thích ngắn bên dưới ảnh.                               |
| `date`                  | Ngày kỷ niệm theo định dạng `YYYY-MM-DD`.                  |
| `description` trong ảnh | Câu chuyện chi tiết về khoảnh khắc đó.                     |

Ví dụ, nếu ảnh nằm tại `images/ngay-dau-tien/anh-01.jpg`, bạn phải khai báo đúng:

`src: "images/ngay-dau-tien/anh-01.jpg"`

Đừng ghi đường dẫn trên máy tính như `C:\Users\...` vì GitHub Pages không thể truy cập thư mục trên máy của bạn.

## 4. Bước 3 — Thêm một ảnh mới vào album

Giả sử bạn muốn thêm ảnh thứ ba vào album “Những ngày đầu tiên”.

Thao tác trên máy tính:

1. Chép ảnh vào `images/ngay-dau-tien/`.

2. Đặt tên ảnh là `anh-03.jpg`.

3. Trong phần `photos`, sao chép một khối ảnh hiện có rồi sửa nội dung thành:

JavaScript

```
{
    src: "images/ngay-dau-tien/anh-03.jpg",
    caption: "Một ngày mình muốn nhớ mãi",
    date: "2026-06-01",
    description: "Chúng mình đã cùng nhau trải qua một ngày thật vui."
}
```

4. Lưu file bằng `Ctrl + S`.

Hãy chú ý: giữa hai khối ảnh trong mảng `photos` phải có dấu phẩy `,`. Khối cuối cùng có thể không cần dấu phẩy.

## 5. Bước 4 — Tạo album mới

Giả sử bạn muốn tạo album “Sinh nhật của chúng mình”.

Bạn sao chép một khối album trong mảng `albums`, sau đó sửa thành ví dụ dưới đây:

JavaScript

```
{
    id: "sinh-nhat",
    title: "Sinh nhật của chúng mình",
    description: "Những ngày sinh nhật đầy niềm vui và bất ngờ.",
    cover: "images/sinh-nhat/anh-bia.jpg",

    photos: [
        {
            src: "images/sinh-nhat/anh-01.jpg",
            caption: "Món quà bất ngờ",
            date: "2026-09-15",
            description: "Một bất ngờ nhỏ khiến ngày hôm ấy đặc biệt hơn."
        }
    ]
}
```

Tiếp theo:

* Tạo thư mục `images/sinh-nhat/`.

* Thêm `anh-bia.jpg` và `anh-01.jpg` vào đó.

* Đặt khối album mới bên trong mảng `albums`, ngăn cách với album trước bằng dấu phẩy.

Website sẽ tự hiển thị album mới ở trang chủ. Khi bấm vào album, ảnh được khai báo trong `photos` sẽ xuất hiện bên trong. Bạn không cần tự tạo thêm nút bấm hay viết lại hàm hiển thị.

## 6. Bước 5 — Tải website lên GitHub Pages

1. Mở repository GitHub đang chứa website của bạn.

2. Tải `index.html` lên repository, thay thế file HTML cũ nếu cần.

3. Tải cả thư mục `images` lên repository, giữ nguyên cấu trúc thư mục.

4. Commit các thay đổi lên nhánh mà GitHub Pages đang sử dụng, thường là `main`.

5. Mở domain GitHub Pages của bạn và tải lại trang để kiểm tra.

Nếu ảnh chưa hiện, hãy kiểm tra tên file, đường dẫn `src`, chữ hoa/chữ thường và xem ảnh đã thực sự được tải lên GitHub chưa.

## 7. Nếu muốn thay giao diện thì chỉnh ở đâu?

Bạn không cần đụng đến phần quản lý ảnh khi chỉ muốn thay giao diện. Trong file `index.html`, các phần đã được chia riêng:

| Muốn thay đổi                           | Tìm phần                |
| --------------------------------------- | ----------------------- |
| Tên website, lời giới thiệu             | Phần 3 và 4             |
| Màu nền, màu chữ, font chữ              | Phần 2 — CSS            |
| Khoảng cách, kích thước album và ảnh    | Phần 2 — CSS            |
| Thêm, xóa hoặc đổi tên album            | Phần 10 — dữ liệu album |
| Thêm, xóa hoặc thay ảnh                 | Phần 10 — `photos`      |
| Cách bấm album, tìm kiếm và xem ảnh lớn | Phần 13–16 — JavaScript |

Lưu ý về quyền riêng tư: GitHub Pages thông thường là website công khai. Nếu repository hoặc website được công khai, người khác có thể xem ảnh và source code. Nếu ảnh là kỷ niệm riêng tư của hai bạn, hãy cân nhắc kỹ trước khi tải lên.
